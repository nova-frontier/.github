# GROUNDSTATE · 基态

**让智能接受现实的约束，让研究留下可检验的证据。**

Grounding intelligence into energy, networks, bodies, workflows, and order.

我们围绕**具身智能、群体智能与多智能体协作**开展研究与工程探索。关心的不只是模型能给出什么答案，也包括：它消耗多少能量，怎样交换信息，如何通过身体作用于环境，以及失败后如何被理解与修正。

“基态”是我们回到基本约束的工程隐喻。以开放的笔记、可运行的工具和可复查的记录，逐步连接想法与现实。

[阅读总纲](https://github.com/nova-frontier/manifesto) · [研究约定](https://github.com/nova-frontier/manifesto/blob/main/rfcs/RFC-001.md) · [参与建设](https://github.com/nova-frontier/manifesto/blob/main/ROADMAP.md)

## 五个研究节点，一条证据链

| 节点 | 核心问题 | 当前入口 |
|---|---|---|
| **01 · 瓦特与比特** / Watt & Bit | 一次任务消耗了多少能量？ | [功率积分与测量协议](https://github.com/nova-frontier/watt-to-token-bench) |
| **02 · 香农港** / Port Shannon | 信息在受限网络里如何到达？ | [可复现的合成信道探针](https://github.com/nova-frontier/edge-swarm-protocol) |
| **03 · 第七自由度** / The 7th DOF | 感知、动作与失败如何被记录？ | [具身现场记录与结构检查](https://github.com/nova-frontier/embodied-field-notes) |
| **04 · 像素人间** / Pixel Mundane | 异常、回退与预算怎样进入工作流？ | [有限尝试的离线事件回放](https://github.com/nova-frontier/mundane-agent-kits) |
| **05 · 权重之上** / Beyond Weights | 来源、版本与使用依据能否追溯？ | [组件清单与复核记录](https://github.com/nova-frontier/agentic-order-spec) |

节点代表研究职责，开放交叉参与，不与某个人、学位或机构一一绑定。

## 从一份笔记开始

提出一个能检验的问题，保存一次完整的运行，记录成功、失败和未知，再让其他人复现。

目前五个节点均处于 **v0.1 起步阶段**：提供标准库 Python 工具、演示输入、测试和记录模板。示例为合成或结构演示；真实硬件测量、跨节点集成和外部验证仍待开展。我们会把实际完成的工作与研究计划分开记录。
