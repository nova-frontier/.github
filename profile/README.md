# GROUNDSTATE · 基态

**从世界中学习，与世界共同行动。**

Intelligence, grounded in the world.

我们是一个围绕**具身智能、群体智能与多智能体协作**展开探索的研究共同体。

我们关心智能如何通过身体感知环境、通过行动获得反馈，又如何在不同个体的交流与协作中形成新的能力。我们希望连接算法与现实，也连接来自不同背景、愿意一起追问和动手的人。

“基态”代表我们的出发点：回到基本问题，理解真实约束，在持续的观察、实验与交流中寻找新的可能。

## 我们关注什么

**具身智能 · Embodied Intelligence**  
从感知到行动，探索身体、环境与学习之间的联系。关注触觉与交互、空间理解，以及真实世界中的反馈与适应。

**群体智能 · Collective Intelligence**  
从个体到群体，探索局部互动如何形成协同行为。关注信息交换、协同决策，以及资源和通信受限时的集体行动。

**多智能体协作 · Multi-Agent Systems**  
从单一能力到共同完成任务，探索智能体之间的分工、交流与协调。关注不同能力如何组合，以及协作过程如何被理解。

## 五种视角，同一个世界

我们用五个名字，记下观察智能系统的不同视角。

| 视角 | 我们追问的问题 |
|---|---|
| **瓦特与比特** · Watt & Bit | 智能如何面对能量与计算资源的边界？ |
| **香农港** · Port Shannon | 信息如何跨越个体，成为协作的基础？ |
| **第七自由度** · The 7th DOF | 身体与环境的交互，如何塑造智能？ |
| **像素人间** · Pixel Mundane | 感知与推理，如何走进具体的日常任务？ |
| **权重之上** · Beyond Weights | 技术如何与人的需求、规则和共同生活相连？ |

这些视角彼此交叉，也向新的问题开放。

## 开放的研究共同体

我们期待把这里建设成交流想法、分享阅读、记录探索与发起合作的共同空间。重视清楚的问题、诚实的记录，也珍惜尚未成熟的灵感和不同学科之间的碰撞。

无论你来自研究、工程、设计，还是其他领域，都欢迎带着具体问题与我们交流。
